# Stock Price Analysis

A Python data analysis project exploring historical stock price data for Apple (AAPL) and Microsoft (MSFT).

## Project URL

https://roadmap.sh/projects/stock-price-time-series

## Objectives

* Download historical stock data using `yfinance`
* Analyze closing prices over time
* Resample daily data into weekly and monthly data
* Calculate 20-day and 200-day moving averages
* Analyze trading volume
* Calculate daily and cumulative returns
* Visualize stock price trends using Matplotlib

## Technologies

* Python
* Pandas
* yfinance
* Matplotlib
* Jupyter Notebook

## Companies

* Apple (AAPL)
* Microsoft (MSFT)

## Time Period

January 2021 – September 2026
